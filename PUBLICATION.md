# Before public release

This is a local, uncommitted privacy-filtered repository. No GitHub remote has been created and nothing has been uploaded.

The code has no selected license yet. Choose an appropriate license for the original scripts and examples before claiming this is open-source. Separately review applicable rights/terms for distributing compiler-derived tables, signatures and data. A license for original code cannot grant rights over third-party material.

No Apple compiler executables, SDK headers, compiled AIR/metallib files or downloaded third-party implementations are bundled. The inventory and observations are version-specific research data, not Apple documentation or an official specification.

Before publishing:
1. Run the offline tests and inspect the privacy audit.
2. Confirm documentation accurately describes incomplete execution coverage.
3. Choose a license and attribution policy appropriate to code versus data.
4. Review staged files, ensure generated outputs are absent, and decide commit-author privacy.
5. Choose the GitHub account/name and public or private visibility explicitly.
